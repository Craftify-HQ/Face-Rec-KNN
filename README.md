# Face-Rec-KNN

ระบบจดจำใบหน้าแบบเรียลไทม์ผ่านกล้องเว็บแคม ด้วย k-Nearest Neighbors (เขียนเองด้วย NumPy)

## โครงสร้าง
- `collect_faces.py` – เปิดกล้องเพื่อเก็บภาพใบหน้า (ภาพขาวดำ) ไว้ในโฟลเดอร์ชื่อเจ้าของหน้า
- `recognition.py` – โหลดภาพทุกโฟลเดอร์มาเป็นข้อมูลเทรน แล้วทายชื่อจากกล้องด้วย k-NN
- `ann/`, `dd/`, `nod/`, `pan/`, `saimai/` – ภาพใบหน้าของสมาชิกแต่ละคน

## ติดตั้ง
```bash
pip install numpy opencv-python matplotlib
```

## วิธีใช้งาน
### 1) เก็บภาพหน้าของตัวเอง
1. เปิด `collect_faces.py` แล้วแก้ `name = 'nod'` เป็นชื่อตัวเอง
2. รันคำสั่ง
   ```bash
   python collect_faces.py
   ```
3. หันหน้าเข้ากล้อง ดูหน้าต่าง "Face Cropped" ว่าหน้าอยู่ในภาพครบ
4. กด `s` เพื่อบันทึกภาพ (แนะนำ 40–50 ภาพ ขยับหน้าเล็กน้อยระหว่างถ่าย)
5. เก็บครบแล้วกด `Ctrl+C` ในเทอร์มินัลเพื่อหยุด

### 2) รันระบบจดจำใบหน้า
```bash
python recognition.py
```
ชื่อที่ระบบทายจะแสดงเป็นตัวอักษรสีเขียวเหนือกรอบสีแดง กด `q` เพื่อออก

## หลักการทำงาน
1. แปลงภาพเป็นขาวดำ ย่อเป็น 100×100 แล้วแปลงเป็นเวกเตอร์ 10,000 ค่า
2. วัดระยะห่าง (Euclidean) ระหว่างภาพจากกล้องกับทุกภาพในชุดข้อมูล
3. เลือกภาพที่ใกล้ที่สุด k ภาพ (ค่าเริ่มต้น k = 1) แล้วโหวตชื่อที่พบมากที่สุด

## ข้อแนะนำ
- ถ่ายภาพในที่ที่แสงสว่างพอ และแสงคล้ายกับตอนใช้งานจริง
- นั่งระยะห่างจากกล้องใกล้เคียงกันทั้งตอนเก็บภาพและตอนใช้งาน
